# Кейс: Исследовательское тестирование коммерческого Web-продукта (VPN-сервис)

## 📌 Описание кейса
В ходе самостоятельного исследовательского тестирования (Exploratory Testing) коммерческого VPN-сервиса была обнаружена критическая уязвимость бизнес-логики на форме регистрации и активации триал-периода. Дефект позволял бесконечно использовать платный функционал сервиса без фактической оплаты.

* **Тип тестирования:** Тестирование бизнес-логики (Business Logic Testing), Функциональное тестирование.
* **Критичность (Severity):** Critical / Blocker (критические финансовые потери для бизнеса).
* **Статус:** Локализован, составлен технический баг-репорт и успешно передан команде разработки.

---

## 🐛 Bug Report: Обход платежного шлюза через абуз триал-периода из-за отсутствия верификации Email

### Окружение (Environment)
* **ОС:** Windows 11
* **Браузер:** Google Chrome
* **Компонент:** Форма регистрации / Модуль подписки

### Шаги воспроизведения (Steps to Reproduce)
1. Открыть главную страницу веб-сайта сервиса.
2. Нажать на кнопку «Получить VPN бесплатно на 3 дня».
3. В открывшейся форме в поле "Ваше имя" ввести любые символы (например, `Test`).
4. В поле "E-mail" ввести строку из случайных символов, **не являющуюся существующим почтовым ящиком** (например, `random_test_12345@nonexistent-domain.xyz`).
5. Нажать кнопку отправки формы / активации подписки.

### Фактический результат (Actual Result)
Система успешно регистрирует аккаунт, генерирует учетные данные для VPN и активирует полноценный триал-период на 3 дня. Подтверждение подлинности почтового ящика (Email Verification / Double Opt-In) полностью отсутствует. Пользователь имеет возможность генерировать неограниченное количество аккаунтов со случайными данными за секунды, получая бесконечный бесплатный доступ.

### Ожидаемый результат (Expected Result)
При вводе Email-адреса система должна отправлять проверочный токен/ссылку на указанный ящик. Активация триал-периода и доступ к продукту должны предоставляться **строго после успешного подтверждения** подлинности Email-адреса (Email Verification).

### Влияние на бизнес (Business Impact)
Уязвимость позволяет недобросовестным пользователям полностью обходить платные тарифные планы, что приводит к прямым финансовым потерям компании, недополученной прибыли и нецелевой нагрузке на сервера VPN-инфраструктуры.
